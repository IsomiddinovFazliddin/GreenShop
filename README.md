🌿 GreenShop – Zamonaviy O'simliklar Do'koni (E-commerce UI)
GreenShop — bu o'simliklar va tabiat ishqibozlari uchun mo'ljallangan, to'liq funksional frontend platformasi. Loyiha React.js va SCSS yordamida, yuqori darajadagi foydalanuvchi interfeysi (UI) va tajribasini (UX) ta'minlash maqsadida yaratilgan.

🚀 Texnologik Stek
React 18 – Komponentlarga asoslangan arxitektura.

SCSS – Modulli va ierarxik stillashtirish tizimi.

React Router DOM – Sahifalararo tezkor va uzluksiz navigatsiya.

Vite – Tezkor yig'uvchi (build tool).

React Icons – Sifatli va minimalist ikonkalar to'plami.

✨ Asosiy Imkoniyatlar
Dinamik Katalog: Mahsulotlarni kategoriyalar bo'yicha saralash va ko'rish.

Savatcha Tizimi: Mahsulotlarni qo'shish, o'chirish va umumiy summani hisoblash.

Doimiy Ma'lumotlar: localStorage integratsiyasi orqali savatchani saqlash.

Dynamic Routing: Har bir mahsulot uchun alohida batafsil ma'lumot sahifasi.

Interaktiv Modallar: Login, Ro'yxatdan o'tish va Savatcha modallari.

Tartibli Kod: Professional papkalar strukturasi.

📦 O'rnatish va Ishga Tushirish
Loyihani ishga tushirish uchun quyidagi qadamlarni bajaring:

Kutubxonalarni yuklash:

Bash
npm install
Loyihani ishga tushirish:

sass - npm i sass
react-icons - npm i react-icons --save
router - npm i react-router-dom

Bash
npm run dev
📝 Eslatma
Ushbu loyiha hozirda Desktop (1200px+) ekranlar uchun to'liq optimallashtirilgan. Mobil qurilmalar uchun moslashuvchanlik (responsiveness) ustida ishlash davom etmoqda.
